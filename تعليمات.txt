==========================================================
⚙️  المتطلبات قبل التثبيت
==========================================================

يجب تثبيت البرامج التالية أولاً على الجهاز الجديد:

1️⃣  Python 3.11
   الرابط: https://www.python.org/downloads/release/python-3119/
   ⚠️  مهم: عند التثبيت فعّل خيار "Add Python to PATH"

2️⃣  Node.js (LTS)
   الرابط: https://nodejs.org/en/download
   اختر الإصدار LTS (الموصى به)

3️⃣  اتصال بالإنترنت أثناء أول تثبيت فقط
   (لتحميل المكتبات)


==========================================================
🚀  خطوات التثبيت والتشغيل
==========================================================

[ الخطوة الأولى - التثبيت (مرة واحدة فقط) ]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. ضع مجلد "مزاين" في أي مكان على الجهاز الجديد
2. انقر نقراً مزدوجاً على ملف: INSTALL.bat
3. انتظر حتى يكتمل التثبيت (5-15 دقيقة حسب سرعة الإنترنت)
4. عند ظهور رسالة "اكتمل التثبيت" اضغط أي مفتاح

[ الخطوة الثانية - تشغيل النظام (في كل مرة) ]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. انقر نقراً مزدوجاً على: تشغيل_مزاين.bat
2. ستفتح نافذتا CMD (إحداهما للخادم والأخرى للواجهة)
3. سيفتح المتصفح تلقائياً على: http://localhost:5173

⚠️  لا تغلق نوافذ CMD أثناء العمل - ستوقف البرنامج

[ إيقاف النظام ]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
انقر نقراً مزدوجاً على: إيقاف_مزاين.bat
أو أغلق نوافذ CMD يدوياً


==========================================================
🌐  روابط النظام

  الواجهة الأمامية:  http://localhost:5173
  واجهة API:          http://localhost:8000
  توثيق API:         http://localhost:8000/docs


==========================================================
❓  حل المشاكل الشائعة
==========================================================

المشكلة: "Python غير موجود"
الحل: تثبيت Python 3.11 مع تفعيل "Add Python to PATH"
      أعد تشغيل الجهاز بعد التثبيت ثم شغّل INSTALL.bat

المشكلة: "Node.js غير موجود"
الحل: تثبيت Node.js من الرابط أعلاه ثم أعد تشغيل INSTALL.bat

المشكلة: المتصفح لا يفتح أو الصفحة فارغة
الحل: انتظر 10-15 ثانية ثم افتح المتصفح يدوياً:
      http://localhost:5173

المشكلة: "Port already in use" (المنفذ مشغول)
الحل: شغّل ملف إيقاف_مزاين.bat ثم شغّل البرنامج مجدداً

المشكلة: بطء في أول تشغيل بعد التثبيت
الحل: طبيعي - نماذج الذكاء الاصطناعي (OCR) تحتاج وقتاً
      للتحميل في المرة الأولى فقط

==========================================================
💡  ملاحظات مهمة
==========================================================

• النظام يعمل محلياً بالكامل - لا يحتاج إنترنت بعد التثبيت
• يمكن الوصول إليه من أجهزة أخرى على نفس الشبكة:
  http://[IP-الجهاز]:5173  (مثال: http://192.168.1.10:5173)
• لمعرفة IP الجهاز: اكتب  ipconfig  في CMD
